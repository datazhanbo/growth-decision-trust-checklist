# 增长决策可信度 Checklist

展博增长实验室开源自检清单：用 15–30 分钟回答「这套数 / 实验 / 决策链路，能不能信？」。

- 站点：[abtest.chat](https://abtest.chat) · 服务：[服务与合作](https://abtest.chat/services/)
- 在线自检：[广告数据快检](https://abtest.chat/tools/checkup/) · [实验能力自检](https://abtest.chat/tools/experiment-checkup/)
- 本仓库：**可打印 / 可 fork 的脱敏清单**，不是完整付费诊断。

## 怎么用

1. 打开 [`checklist.md`](./checklist.md)，按四块勾选。
2. 用 [`scorecard.md`](./scorecard.md) 打分（每项 0–2）。
3. 总分偏低或某一块全红 → 适合预约适配沟通，不必先买诊断。

## 不是什么

- 不是两周正式诊断报告
- 不替代管理层对齐
- 不承诺业务结果
